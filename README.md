# SensiWeld Website

Marketing website for [SensiWeld](https://sensiweld.com) — bio-based adhesives and ultrasonic welding for natural-fibre composites. Born at TU Delft.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Deployed on Netlify

## Getting started

```bash
npm install
npm run dev
```

## Build and deploy

```bash
npm run build
netlify deploy --prod --dir=dist
```

## Structure

```
src/
  pages/       # Home, About, Product, Team, Applications, Contact
  components/  # Navbar, Footer
  assets/      # Images and logos
  config/      # Supporters config
archive/       # Original version of the website (preserved for reference)
```
